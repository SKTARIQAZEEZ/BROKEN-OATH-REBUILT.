# BROKEN OATH — Rebuilt Project

A clean-room third-person 3D action-adventure foundation. This repository is the new development line; it does not depend on v051.

## Run locally
Serve this directory over HTTP (ES modules require a local server), then open the local URL. Example: `python -m http.server 8000`.

## Controls
- WASD: move; mouse drag: orbit camera
- E: interact with mission marker / nearby characters
- Space: melee attack
- C: crouch
- Escape: pause
- Touch controls are provided for mobile browsers.

## Canon
Azeez, Ranvir and Ananya grow up together. Azeez leaves for a dangerous operation after promising Ananya he will return. While he is away, Devraj's gang attacks Ranvir's family home. Devraj manipulates Ranvir with lies, including that Azeez is dead, and separately tells Anjali and Ananya that the men they love are dead. Years later Azeez returns, uncovers the truth, rescues Anjali and Ananya, and helps Ranvir confront Devraj. Anjali saves Ranvir in the final battle. Azeez and Ananya marry; the final exchange is: “You actually kept your promise.” / “We did. Together.”

## Development status
This is the initial playable foundation, not a completed game. Original authored character models, mocap/animation clips, recorded voice acting, bespoke chapter environments and full device QA must be added and validated in later milestones.
